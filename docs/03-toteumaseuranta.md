# Toteumaseuranta

Toteumaseuranta kuuluu ensimmäiseen versioon.

## Työnkulku

1. Työnjohtaja laatii yleisaikataulun.
2. Aikataulu tallennetaan tavoitteeksi.
3. Ennen työmaakokousta asetetaan seurantahetki.
4. Tehtäville kirjataan valmiusaste ja tarvittaessa toteutunut alku, loppu sekä ennustettu loppu.
5. Tulosteessa näkyvät tavoite, toteutuma, jäljellä oleva osuus ja seurantahetki.

## Kirjaustapa

Toteuma kirjataan käsin. Tuntivahti voi myöhemmin ehdottaa valmiusastetta, mutta se ei saa määrätä aikataulun toteumaa automaattisesti.

# V1-käyttöpolku

1. Käyttäjä perustaa tyhjän projektin.
2. Hän lisää yleisaikataulun pää- ja alatehtävät vapaasti.
3. Tehtävät ajoitetaan päivämäärillä tai janasta vetämällä.
4. Valmis suunnitelma tallennetaan tavoitteeksi.
5. Noin kerran kuukaudessa asetetaan seurantahetki ja kirjataan toteuma.
6. Seurantatuloste tehdään A4- tai A3-vaakamuodossa työmaakokoukseen.
7. Viikkoaikataulu voidaan myöhemmin tehdä erillisenä tarkempana näkymänä.

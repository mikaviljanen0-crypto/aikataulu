# v1.0 – viikkoaikataulu

## Ero yleisaikatauluun

Yleisaikataulu kuvaa työmaan päävaiheet. Viikkoaikataulu toimii yksityiskohtaisempana lyhyen aikavälin suunnitelmana.

Viikkoaikataulu ei vaadi, että kaikki rivit ovat peräisin yleisaikataulusta. Työnjohtaja voi lisätä esimerkiksi:

- materiaalitoimituksen
- tarkastuksen
- suojauksen
- siivouksen
- työn aloitusedellytyksen
- yksittäisen asunnon tai julkisivun työtehtävän

## Tilan seuranta

Viikkotehtävällä on neljä tilaa:

- Suunniteltu
- Käynnissä
- Valmis
- Estynyt

Estynyt tehtävä korostetaan punertavalla taustalla ja käynnissä oleva kellertävällä taustalla.

## Tulostus

Viikkoaikataulu on tarkoitettu ensisijaisesti A4-vaakatulosteeksi työmaan päivittäiseen käyttöön ja viikkopalaveriin.

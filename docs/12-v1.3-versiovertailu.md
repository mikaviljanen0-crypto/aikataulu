# v1.3 – aikatauluversioiden vertailu

## Vertailun rakenne

Vertailu tehdään tehtävän yksilöllisen tunnisteen perusteella. Molemmista versioista muodostetaan tehtäväkartta.

Tehtävä luokitellaan:

- lisätyksi, jos se löytyy vain uudemmasta versiosta
- poistetuksi, jos se löytyy vain vanhemmasta versiosta
- muuttuneeksi, jos jokin seurattava kenttä eroaa

## Seurattavat kentät

- nimi
- alku
- kesto
- hierarkiataso
- rakennus tai alue
- vastuuhenkilö
- edeltävä tehtävä
- viive
- väri

Toteumat eivät kuulu aikatauluversioiden vertailuun, koska niitä käsitellään erillisessä seurantahistoriassa.

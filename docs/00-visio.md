# Visio

Ohjelmisto on rakennusliikkeen yleis- ja seuranta-aikataulujen laatimiseen tarkoitettu web-sovellus.

Tyypillinen käyttö:

- 10–20 projektia vuodessa
- saneerauskohteet, joissa voi olla useita rakennuksia
- projektit voivat jatkua usealle vuodelle
- yleisaikataulu laaditaan yleensä työmaan alussa
- toteumaa päivitetään noin kerran kuukaudessa työmaakokousta varten
- tuloste on useimmiten A4, tarvittaessa A3

Ensimmäisen version ei tarvitse sisältää resurssiaikataulutusta, moniprojektia tai monimutkaista riippuvuuslaskentaa.

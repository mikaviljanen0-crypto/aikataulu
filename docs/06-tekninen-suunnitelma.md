# Tekninen suunnitelma

## Ehdotettu tuotantopino
- Next.js + TypeScript
- PostgreSQL / Supabase
- Prisma tai Drizzle ORM
- SVG/HTML-pohjainen oma Gantt-editori
- Playwright tulostus- ja käyttöliittymätesteihin

## Keskeiset entiteetit
- Project
- ScheduleView
- Task
- Calendar
- Baseline
- ProgressSnapshot
- Dependency
- PrintPreset
- ImportJob

Prototyyppi on tarkoituksella riippuvuudeton, jotta käyttölogiikka voidaan hyväksyä ennen tuotantoarkkitehtuurin rakentamista.
